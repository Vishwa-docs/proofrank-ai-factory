# Judge Replay Handoff

ProofRank has two replay modes:

1. Verified receipt mode: no private review token needed. Judges can open the Native.builder app and inspect the Bright Data evidence receipt, exported memo, and evidence path.
2. Live replay mode: optional, token-protected, server-side Bright Data run for a judge-supplied GitHub repo and demo URL.

- Public API review endpoint: `https://proofrank-ai-factory.vercel.app/api/review-project`
- Security probe passed: unauthenticated POST returns `401`; authenticated disallowed-host POST returns `422`.
- Final Bright Data receipt: `submission/final-brightdata-receipt.json`
- Bright Data evidence bundle in the receipt: `scrape_as_markdown`, `search_engine`, and `discover`.

## Safe Judge URL

Use a URL fragment so the review token is not sent during the first page load:

```text
https://proofrank-ai-factory.vercel.app/#reviewToken=YOUR_REVIEW_TOKEN
```

The app stores the token in session storage, removes it from the visible URL, and sends it only as `x-proofrank-token` when the judge runs a live review.

Do not paste this tokenized URL into the public lablab submission. Use the normal Native.builder URL publicly, and share the tokenized replay URL only if a judge or sponsor asks for a fresh live run.

## Spend Guardrails

Keep these server-side values for live replay:

```text
PROOFRANK_FETCH_MODE=mcp
BRIGHTDATA_MCP_TOOLS=search_engine,scrape_as_markdown,discover
PROOFRANK_MAX_BRIGHTDATA_CALLS=12
PROOFRANK_BRIGHTDATA_CAP_USD=20
PROOFRANK_ALLOWED_HOSTS=github.com,*.github.io,*.vercel.app,lablab.ai,*.nativelyai.app
```

If the Bright Data token is not uploaded to Vercel, the public API remains a secured shell and the final evidence record should be the local Bright Data receipt. Uploading `BRIGHTDATA_API_TOKEN` or rotating `PROOFRANK_REVIEW_TOKEN` grants persistent server access, so do it only from the account owner context.

## Replay Success Criteria

A fresh live replay is sponsor-grade only when the exported receipt includes all three executed Bright Data traces:

```json
[
  { "provider": "bright-data", "traceStatus": "executed", "tool": "scrape_as_markdown" },
  { "provider": "bright-data", "traceStatus": "executed", "tool": "search_engine" },
  { "provider": "bright-data", "traceStatus": "executed", "tool": "discover" }
]
```

If Vercel times out on a full replay, keep Vercel as the public app/API shell and use the local Bright Data receipt generated by:

```bash
PROOFRANK_FETCH_MODE=mcp npm run final:receipt -- https://github.com/Vishwa-docs/proofrank-ai-factory https://proofrank-ai-factory.vercel.app/
```
